# Precision Snake

A polished, from-scratch implementation of Snake built with **vanilla JavaScript and the HTML5 Canvas API — no frameworks, no dependencies**.

Built as a portfolio piece to demonstrate frontend fundamentals: clean game-loop architecture, canvas rendering, input handling (keyboard + touch), responsive layout, accessibility considerations (`prefers-reduced-motion`, focus states), and persisted state via `localStorage`.

## Features
- Smooth fixed-timestep game loop (`requestAnimationFrame` + accumulator)
- Responsive, device-pixel-ratio-aware canvas rendering
- Keyboard (arrow keys / WASD) and touch (swipe) controls
- Increasing difficulty as the snake grows
- Persistent high score
- Reduced-motion support

## Run it
Just open `index.html` in a browser — no build step, no install.
